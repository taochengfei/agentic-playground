# apps/

One directory per web app. Each app is self-contained with `index.html` as the entry point.

| App | What it is |
|---|---|
| [cmb](cmb/) | CMB as the receding boundary of the observable universe; drag to look around, slider/space to advance "now". |
| [flow-field](flow-field/) | Canvas particle animation following an evolving noise field. Click to burst, `space` to pause, `b` to toggle color mode. |

To add a new app: create a directory here, put `index.html` in it, and add a row to the tables in this file and the root `README.md`.
